# DReport

DReport is a standalone macOS application for structured daily work
recording, hierarchical task management and reporting.

The project is currently under initial development.

Core goals:

- unlimited task/subtask depth;
- tasks, notes and activity entries;
- To Do / In Progress / Completed workflow;
- chronological work history;
- themes;
- organizations and sub-organizations;
- groups and people with multiple affiliations;
- semantic relationships describing for whom work is performed;
- daily reporting;
- portable export;
- local-first storage;
- no user-specific defaults.

See `Docs/V0.1-SPEC.md` for the current application specification.
